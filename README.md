# BIOSCOPE 🦑

A trilingual tutoring platform for private lessons in Sciences de la Nature et de la Vie (SNV), biology, and microbiology, from CEM through Master's level, in Algeria. Built and run by Zekraoui Rabah Allaa Eddine, a Master's student in Microbiology and Quality Control (USTHB).

## Services

- **SNV — CEM & Lycée** — private lessons aligned with the Algerian curriculum, exam prep for BEM and BAC
- **Biology & Microbiology — L1 to M2** — session support for university-level modules, exam and TD/TP revision
- **Rapport de stage / TP** — help structuring and writing lab/internship reports
- **Exposé & Poster** — content and design help for academic presentations
- **Pack mensuel** — recurring monthly session packs for CEM/Lycée and university students

## Features

- Fully trilingual: French, English, Arabic (with RTL layout support)
- Online booking via WhatsApp or email, with live slot availability calendar
- Student accounts: profile, booking history, message history with admin replies
- Promo codes with optional usage limits
- Reviews system. 
- Personal module progress tracker for students
- Live "students helped" counter and structured data (schema.org) for search visibility
- Digital business card with QR code
- Dark/light theme with system preference support
